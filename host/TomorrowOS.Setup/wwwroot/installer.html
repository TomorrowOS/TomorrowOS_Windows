    Install TomorrowOS Windows Player

    TomorrowOS will prepare this Windows device for reliable digital signage playback. Content plays from a local cache, so the screen keeps running when the network or CMS does not.

    Version
    1.0.0
    Install location
    C:\Program Files\TomorrowOS
    Local cache
    C:\ProgramData\TomorrowOS\cache
    Disk required
    ≈ 500 MB + cache
    Silent install
    TomorrowOS-Windows-Setup.exe /silent /cms "https://cms.example.com" /passcode "secret" /orientation landscape /harden

    Each device still stores its own maintenance passcode hash locally.

    Installation options

    These choices decide how much of Windows TomorrowOS takes over. They can be changed later from the CMS or from maintenance mode.

    Prepare Windows for signage

    TomorrowOS will apply the following system changes. Recommended items are on by default. Turning off an essential item leaves the screen able to show Windows to the public.

    Windows updates stay enabled. Security updates remain on and will be scheduled outside playback hours, inside the maintenance window you choose.

    Protect local device access

    Ordinary users cannot close or leave the player. Authorised technicians enter maintenance mode using a secure key combination and this device passcode.

      Use a passcode unique to this site. A single passcode reused across a whole fleet is the most common cause of unauthorised screen access.

      How a technician gets in

      1. Hold Ctrl+Shift+Alt+M on the device.
      2. Enter this device passcode when prompted.
      3. Choose an approved maintenance action.
      The passcode is hashed and stored on this device only. There is no universal master password.

      Installing TomorrowOS

      This takes about a minute. Do not power off the device.
